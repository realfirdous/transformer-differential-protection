# Transformer Differential Protection Relay Using MATLAB/Simulink

## Overview
This project focuses on modelling a transformer differential protection relay using MATLAB/Simulink to study internal transformer fault detection.

## Objectives
- Model differential protection logic using current comparison.
- Analyse differential current under normal operating conditions.
- Study relay response under internal and external fault conditions.

## Tools Used
- MATLAB
- Simulink
- Power System Protection

## Simulation Results
Simulation results and graphs will be added here to demonstrate relay response under normal, internal-fault, and external-fault conditions.

## Project Files
The repository will contain the Simulink model (`.slx`), MATLAB scripts (`.m`), and relevant simulation results as they become available.
